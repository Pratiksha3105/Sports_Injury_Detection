# Wireframes

Low-fidelity wireframes for the core Milestone 1 screens, generated to
communicate layout and hierarchy before/alongside the final Tailwind UI.

| File | Page |
|---|---|
| `01-home-wireframe.png` | Home / Landing page |
| `02-login-wireframe.png` | Login |
| `03-register-wireframe.png` | Register |
| `04-dashboard-wireframe.png` | Dashboard |
| `05-upload-video-wireframe.png` | Upload Video |
| `06-prediction-history-wireframe.png` | Prediction History |
| `07-athlete-profile-wireframe.png` | Athlete Profile |

The actual implemented UI (glassmorphism, gradients, animations) is a
high-fidelity evolution of these layouts — see `frontend/src/pages/` for
the real components, or run the app locally to view it live.
