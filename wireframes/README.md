# Wireframes

Low-fidelity layouts for KinetIQ's three pages.

| File | Page | Route |
|---|---|---|
| `01-home-analyze-wireframe.png` | Upload & Analyze | `/` |
| `02-auth-wireframe.png` | Sign in / Sign up | `/auth` |
| `03-profile-wireframe.png` | Athlete profile | `/profile` |

The real UI (shadcn/ui + Tailwind v4) is a polished, animated evolution of
these layouts — run `npm run dev` to see it live.
