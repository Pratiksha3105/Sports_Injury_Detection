# API Documentation (Milestone 1)

Interactive, always-current docs are auto-generated by FastAPI at
`http://localhost:8000/docs` (Swagger UI) once the backend is running.
This file is a static summary for quick reference.

Base URL: `http://localhost:8000/api/v1`

## Authentication

### `POST /auth/register`
Create a new account.
```json
{
  "full_name": "Jane Doe",
  "email": "jane@example.com",
  "password": "supersecret123",
  "role": "athlete",
  "phone": "+91 90000 00000"
}
```
Returns the created user (`201 Created`).

### `POST /auth/login`
`application/x-www-form-urlencoded`, standard OAuth2 password flow:
`username` (email) + `password`.
```json
{
  "access_token": "…",
  "refresh_token": "…",
  "token_type": "bearer"
}
```

### `POST /auth/logout`
Client-side token discard (JWT is stateless in Milestone 1).
